Exam Scanner (PWA)

วิธีใช้งานโดยย่อ
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, manifest.json, sw.js และโฟลเดอร์ icons) ไปไว้บนเว็บ https
   ต้องวางไว้ที่โฟลเดอร์เดียวกัน อย่าเปลี่ยนชื่อไฟล์
   เช่น Netlify Drop (app.netlify.com/drop) ลากทั้งโฟลเดอร์ไปวาง หรือ GitHub Pages
2. เปิดลิงก์บนมือถือ
   Android (Chrome): เมนู 3 จุด > ติดตั้งแอป
   iPhone (Safari): ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
3. เปิดแอปจากไอคอน ตั้งค่ากระดาษและเฉลย แล้วใช้ปุ่ม "สแกนสดต่อเนื่อง" ในแท็บตรวจ

เมื่อแก้ไข index.html ในภายหลัง ให้เปลี่ยนเลขเวอร์ชันในบรรทัดแรกของ sw.js (เช่น exam-scanner-v1 เป็น v2)
เพื่อให้เครื่องที่ติดตั้งไว้โหลดเวอร์ชันใหม่
